# SMALL-GAME-
# 🎮 Tic-Tac-Toe Game

A simple and interactive **Tic-Tac-Toe game** built using **HTML, CSS, and JavaScript**.  
This project focuses on **DOM manipulation, game logic, and UI state control**.

---

## 🚀 Features

- Two-player gameplay (X vs O)
- Turn-based logic
- Win detection using predefined patterns
- Winning message display
- Reset game functionality
- New Game button appears only after a win
- Buttons disabled after a win to prevent further moves
- Clean and responsive UI

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the game
- **CSS3** – Styling and layout
- **JavaScript (Vanilla)** – Game logic and interactivity
- 

## 🎯 How the Game Works

1. The game starts with **Player O**
2. Players take turns clicking on empty boxes
3. Each click places either **O** or **X**
4. The game checks for a winning pattern after every move
5. When a player wins:
   - A congratulatory message is shown
   - All boxes are disabled
   - The **New Game** button becomes visible
   - The **Reset** button is hidden
6. Clicking **New Game** resets the board and starts a new match

---

## 🧠 Winning Patterns

The game checks the following combinations:

- Rows
- Columns
- Diagonals

These are stored as index patterns in JavaScript for efficient checking.
